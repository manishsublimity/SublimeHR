# SublimeHR v1 backup

A snapshot of the site as it was before the version 2 redesign (home page and all inner pages).

- `src/`, `static/`, `build.mjs`: the full v1 source. To rebuild v1: copy these three back to the project root, then `node build.mjs`.
- Git tag `v1-backup` points at the last commit that still had v1 as the live design.

Delete this whole folder (and the tag) only when you have approved the v2 pages.
